# opencinedji (candidate)

DJI integration package from VENDOR-01: DUML/datalink, BLE adverts, camera models and status, commands, station join, DJI color data, and the DJI CameraSession adapter behind `DJIControlPort`. Depends only on OpenCineCore/OpenCineMedia. Status `candidate`: consumed by the Pocket `opencine/integration` branch via a path dependency. The Kotlin DJI session still lives in the Pocket app.
Build and test instructions: its own `AGENTS.md`.
