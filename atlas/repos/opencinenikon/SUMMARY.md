# opencinenikon (candidate)

Nikon integration package from VENDOR-02: PTP/IP and USB wire, Nikon properties/profiles/media naming, discovery/connect/session policy, and `NikonCameraSession`. Depends only on OpenCineCore. Status `candidate`: consumed by the OpenZCine `opencine/integration` branch (via OpenZCineCore re-export). The Android JNI facade and Kotlin session remain in the app.
Build and test instructions: its own `AGENTS.md`.
